# data-profile

Ways of drawing a dataset: one mark per item, grouped and coloured by whatever you know about the
items. Each view is its own package, so you install only the one you draw.

| Package                                             | What it is                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------- |
| [`@data-profile/fingerprint`](packages/fingerprint) | Marks laid along the ridges of a Dermatoglyphic (real-looking fingerprint) |
| [`@data-profile/waffle`](packages/waffle)           | A view: one cell per item in a grid, each category a run                   |
| [`@data-profile/core`](packages/core)               | What every view shares: the data contract, encoding and legends            |
| [`@data-profile/react`](packages/react)             | What every view shares in React: the canvas, legends, lists and renderers  |

**[Documentation and live demos](https://sirkettle.github.io/data-profile/)**

See [CONTRIBUTING.md](CONTRIBUTING.md) to work on the packages.
