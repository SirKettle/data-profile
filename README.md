# data-profile

Ways of drawing a dataset: one mark per item, grouped and coloured by whatever you know about the
items. Each view is its own package, so you install only the one you draw.

| Package                                             | What it draws                                             |
| --------------------------------------------------- | --------------------------------------------------------- |
| [`@data-profile/fingerprint`](packages/fingerprint) | Marks laid along the ridges of a real-looking fingerprint |

**[Documentation and live demos](https://sirkettle.github.io/data-profile/)**

See [CONTRIBUTING.md](CONTRIBUTING.md) to work on the packages.
